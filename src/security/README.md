# Security stack

Security services for the people of your organisation: a password vault, and a NetBird client
for the overlay network. On the website: [Security Stack](https://tappaas.org/stacks/security/).

The modules below are this stack's solution: install them in the order listed, or all at once
with `module-manager add-stack security` once #763 is built. Each module's own README says what you
get; its INSTALL.md what you must do by hand.
