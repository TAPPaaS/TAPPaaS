# AI stack

Local AI for your organisation: a GPU model server, one gateway every client uses, and a chat
front end — no prompt leaves your site. How the parts fit: [DESIGN.md](DESIGN.md). On the
website: [AI Stack](https://tappaas.org/stacks/ai/).

The modules below are this stack's solution: install them in the order listed, or all at once
with `module-manager add-stack ai` once #763 is built. Each module's own README says what you
get; its INSTALL.md what you must do by hand.
