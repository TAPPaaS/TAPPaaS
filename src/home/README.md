# Home stack

Home automation: Home Assistant, and the Zigbee gateway it talks to. On the website:
[Home Stack](https://tappaas.org/stacks/home/).

The modules below are this stack's solution: install them in the order listed, or all at once
with `module-manager add-stack home` once #763 is built. Each module's own README says what you
get; its INSTALL.md what you must do by hand.
