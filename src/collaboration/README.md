# Collaboration stack

Files, calendars, office documents and calls for your organisation: Nextcloud with document
editing, and the Talk call stack (signalling and TURN). On the website:
[Collaboration Stack](https://tappaas.org/stacks/collaboration/).

The modules below are this stack's solution: install them in the order listed, or all at once
with `module-manager add-stack collaboration` once #763 is built. Each module's own README says what you
get; its INSTALL.md what you must do by hand.
